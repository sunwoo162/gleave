## Environment-dependent verification

- [ ] `docker build -t npc:v1.0.0-rc .`
- [ ] `docker compose -f docker-compose.example.yml up --build`
- [ ] Container health check returns `healthy`.

Docker Desktop was unavailable on the development host during this candidate
run. The tag workflow repeats these checks on `ubuntu-latest` before creating
a GitHub Release. It runs `npm run smoke:docker-release`, which starts the
example Compose stack, waits for the container health check to become
`healthy`, and removes the temporary container and volume before publishing.
