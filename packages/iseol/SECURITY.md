# Security policy

Please do not report vulnerabilities in a public issue. Send a private report
to the repository maintainers with reproduction steps, affected versions,
impact, and any safe mitigation. Never include live tokens or personal data.

NPC is a self-hosted application. Operators are responsible for protecting
their `.env`, data directory, reverse proxy, and third-party credentials.
Keep optional integrations disabled until their scopes and destinations have
been reviewed.

We will acknowledge a report when received, validate the impact, and publish
a fix or mitigation when practical. Please allow reasonable time for a fix
before public disclosure.
