# Changelog

All notable changes to OSS Product Builder are documented here.

## [0.1.0] - 2026-10-04

Initial open-source MVP release preparation:

- local FastAPI workbench for OSS research, approval, execution, and reports;
- deterministic demo mode and optional GitHub/OpenHands integrations;
- browser UI, optional desktop coordinator, and design-reference verification;
- installable console entry point, package artifact validation, and Docker path;
- contributor, security, and manual release documentation.
